```powershell
.\scripts\start-local-emulators.ps1
```

## Capture notes

- Figures 2, 3, and 5 can be captured in one review session if the same real submitted task remains available; capture separately when the report needs distinct screen framing.
- Figure 4 documents the specified OTP flow. QR scanning is intentionally omitted because it is not required by the specification.
- Never display fabricated OTPs, balances, ratings, names, proof photographs, or transaction entries. Do not expose account credentials or private contact details in report images.
- Before marking any item ready, verify the corresponding data and behavior against the local emulator. The current verified automated checks are Cloud Functions build/tests and Android unit tests/debug APK assembly; these do not constitute the two-account end-to-end or emulator-restart tests.
- Localization is not complete. Do not present an English-only screen as evidence of completed localization.
